# Правила управления памятью

## Сохранение памяти в файл
- **Когда сохранять:** Когда пользователь просит что-то запомнить.
- **Формат:** Создайте файл в текущем проекте в `.agents/memory/` с именем, содержащим дату и время (ГГГГ-ММ-ДД_ЧЧ-ММ). Используйте команду `date` в Bash для получения точного времени. Пример: `2026-06-28_14-30.md`.
- **Содержимое:** Только запоминаемая информация, без заголовков и дополнительных полей.

## Вспоминание
- Файлы `.agents/memory/*.md` — это запомненная информация из предыдущих сессий разговоров. Она автоматически доступна вам через системный промпт.
- Она не обязательно может быть актуальной; противоречащая информация из файла с более поздней датой является приоритетной.
