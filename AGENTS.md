# Инструкции для агентов

## Суть проекта

Настройка ИИ-агента для проектов с открытым исходным кодом, которые хотят давать
читателям не только код, но и знания. Репозиторий собирает промпты, правила,
инструменты, скилы и карточки знаний, чтобы обсуждать с другими, для чего нужен
тот или иной блок системного промпта и помогает ли он. Это текстовый проект:
сборки, тесты и проверки в нём отсутствуют, команды искать не нужно. Основной
результат — ясные тексты.
