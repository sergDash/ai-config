title: Поиск ролей агентов в opencode
summary:
  Роль агента — md-файл с шапкой и системным промптом; opencode ищет её в ~/.config/opencode/agents/, в .opencode/agents/ проекта и в ~/.opencode/agents/.
  Проектная роль перекрывает глобальную, загрузка проверяется командой opencode debug agent <имя>.
date: 2026-10-07

Роль агента в opencode — это Markdown-файл: шапка с полями вроде `description`, `mode`
и `tools`, затем тело — системный промпт роли. Подключается она не полем `instructions`,
а отдельным обходом каталогов конфигурации. opencode проверяет три места:

- `~/.config/opencode/agents/` (или `agent/`) — глобальный каталог, роли действуют
  во всех проектах. В настройках этого окружения он — символическая ссылка
  на `~/.agents/agents/`.
- `.opencode/agents/` каталогов проекта — поиск идёт вверх от текущего каталога до
  корня git-дерева, поэтому файл в корне подхватывается при запуске из любой папки
  проекта.
- `~/.opencode/agents/` — домашний каталог `.opencode`.

Каталоги обходятся в порядке «глобальный, затем проектные», определения сливаются
поверх друг друга, поэтому при совпадении имени проектная роль перекрывает глобальную.

Загруженное определение проверяется командой:

```bash
opencode debug agent Code
```

Она печатает разрешённую роль — имя, режим, разрешения. Достоверный способ узнать,
какой файл прочитан: изменить в нём `description` и убедиться, что команда показывает
новое значение. Так на версии 1.18.34 подтверждается, что opencode читает проектный
`.opencode/agents/Code.md`.

Связка с созданием: `opencode agent create` при выборе области «Current project»
кладёт файл в `.opencode/agents/` рабочего дерева, при выборе «Global» — в
`~/.config/opencode/agents/`.
